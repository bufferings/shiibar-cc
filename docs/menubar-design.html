トレイアイコン表示仕様

メニューバーのトレイアイコンの見た目の正はこのファイル。ポップオーバーとウィンドウの見た目の正は window-design.html。挙動(状態モデル・通知・接続)の正は DESIGN.md §3 / §4.5。

デザイン原則

  • 色は、右肩の点の 2 色だけ: オレンジ = waiting のセッションがいる(あなたの操作を待って止まっている)、 アクセントカラー = 未確認(unreviewed)のセッションがいる(waiting がいないとき)。 窓とグリフには色を使用しない。status は記号と濃度でも表す — !(waiting・太)/ ✻ と 3 つの点(working)/ ✻ だけ(idle・全体 0.8)。色の意味は DESIGN.md §3.1
  • Claude が居る窓: トレイ = フルハイトの角丸窓 + 左上スロットの 1 グリフ (Claude Code のスピナー文字)+ working のときだけ下段の 3 つの点。この組み合わせがロールアップを表す — 「ターミナルで Claude Code が動いている姿」をそのまま記号化したもの
  • 太さと形・濃度の階層でも優先順位を示す: ! は太く、working は 3 つの点が加わり、 idle・切断は全体の減光で沈む。点の色を判別できない場合も、グレースケールだけで優先順位が読める
  • アイコンは操作ボタンを描かず、状態そのものを描く(▶/⏸ のようなメディアボタン文法は逆読みされるため不採用)

トレイ: 角丸の窓 + 左上スロットの 1 グリフ + working の 3 つの点(ロールアップ・常に 1 枠)

  • ロールアップ優先度: waiting > working > idle。トレイは全セッションの状態の代表 1 表示
  • テンプレートアイコン(モノクロ・メニューバーの文字色に自動追従)。暗い壁紙のバーでは白いグリフになる
  • 左上スロット(素の U+273B、x 6.4 基準)のグリフと、下段の 3 つの点の有無で状態を表す: idle・エージェントなしは ✻ だけ / working は ✻ の下に 3 つの点を並べる / waiting は ✻ と入れ替えで太い !(✻ の約 1.1 倍)。 どの状態も静止画で、アニメーションは使用しない(画像を変更するたびに一定の処理時間が必要なため。 DESIGN.md §8.51)。グリフと点だけなので、テンプレート画像のまま成立する
  • 点は窓の右肩に配置し、細い明色フチ(ハロー)を常時描く (明色バーでは実質不可視。ハローは、バーの色による条件分岐をしない)。点は 1 つで、オレンジを優先する (waiting と未確認の両方がいる場合は、オレンジの点だけを表示する)。位置と大きさは、色に関係なく同じである
  • 点の色: オレンジは systemOrange、アクセントカラーは controlAccentColor で、 どちらも、メニューバーのボタンの外観(明るいか暗いか)で解決した色を使用する。アクセントカラーの設定を変更したときは、 点の色も変化する(システムの色の変更の通知で、画像を描画し直す)。下の図の色は、既定のアクセントカラー(青)の例である
  • 減光は 2 段階: idle = 全体 0.8 / エージェントなし = 0.45(値は実機調整。 idle と切断の見分けはこの濃度差のみ)。 daemon 切断中はトレイ全体をエージェントなしと同じ減光にする(古いロールアップを正常と誤認させない。DESIGN.md §4.5)。 切断中も、最後に受け取った一覧で点の種類を判定し、同じ減光で表示する

実装ノート

  • トレイは二層合成: 窓 + スロットグリフのテンプレート層(モノクロ・自動追従)の上に、 色の点を別レイヤーで重ねる。単一 NSImage に色を描いてテンプレート指定すると色が失われる点に注意。 スロットの ✻ と ! は文字グリフ(attributed string)、working の 3 つの点と右肩の点は自前描画
  • ✻ は素の Unicode 文字グリフ(U+273B TEARDROP-SPOKED ASTERISK 系の文字記号)のまま使い、 Anthropic ロゴのサンバースト形状には寄せない(ブランド流用回避。公開リポジトリなので特に)
  • 線の太さ・間隔・光学調整はすべて実機(Retina レンダリング)で最終決定。実機確認項目: ✻ と枠の間隔が融合して見えないか / ✻ の花弁が小サイズで潰れないか (潰れる場合は 9.5pt → 10.5pt まで戻してよい) / working の 3 つの点が小サイズで判別できるか / 点のハローが各種メニューバー色で機能するか / オレンジの点とアクセントカラーの点を、明るいバーと暗いバーの両方で判別できるか (アクセントカラーの設定を変更した場合を含む)
  • トレイのロールアップは「waiting 2 台」と「1 台」を区別しない(意図的な割り切り。内訳は、アイコンのクリックで開く一覧(ポップオーバーまたはウィンドウ)が示す — window-design.html)
