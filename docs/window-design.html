ポップオーバーとウィンドウの表示仕様

ポップオーバーとウィンドウの見た目の正はこのファイル。挙動(開閉・幅による切り替え・ キー操作・一覧の区画・検索・会話ペイン・Resume / Branch / Jump)の正は DESIGN.md §4.5 / §4.6。 トレイアイコンの見た目は menubar-design.html。

ポップオーバーとウィンドウは同じ内容を表示し、レイアウトは 1 種類である。 実行中のセッションと過去の会話を 1 つの一覧に表示し、選択した会話の全文を会話ペインに表示する。 幅が狭いときは一覧のページと詳細ページを切り替え(1 列)、広いときは一覧と会話ペインを並べる(2 列)。

デザイン原則

  • 色: 赤 = 未確認(unreviewed)と、閉じている Running の印、黄 = スター専用。 青(アクセントカラー)は、選択・You のラベル・ピンの ON・主ボタン・ テキストボタン・行のドラッグの移動先の表示(線、強調の枠、見出しの案内)に使用する。 status(waiting / working / idle)には色を使用しない — 記号と濃度で表す(DESIGN.md §3.1 / §8.49)
  • レイアウトは 1 種類: ポップオーバー、細いウィンドウ、広いウィンドウは、 同じ構成要素(見出し行・一覧・会話ペイン・フッター)を表示する。幅によって変化するのは列の数だけである
  • 行のクリックは選択、実行は下部パネルのボタン: 行のクリックは、行を選択するだけである。 Jump / Resume / Branch は、選択中の行を対象にするラベル付きのボタン 1 組だけを下部パネルに表示し、 行の中には配置しない。下部パネルは一覧のページと詳細ページで同じ位置にあり、 Branch と主ボタンは、ページを切り替えても移動しない(View は一覧のページだけに表示する)。ボタン以外の実行の操作は、一覧にフォーカスがある間の ↩ と ⌘↩ と、 行のダブルクリック(↩ と同じく、選択した行の Jump / Resume を実行する)と、⌘ を押しながらのダブルクリック (⌘↩ と同じく、Branch を実行する)である。1 列で詳細ページを開くのは、下部パネルの View ボタンと 一覧にフォーカスがある間の → である。行の中には、詳細ページを開くボタンを配置しない (DESIGN.md §4.5「実行のボタン」「詳細ページを開く操作」「行のクリック」「行のダブルクリック」)
  • キーの割り当てを画面に表示する: 実行のキーと、詳細ページを開くキーは、下部パネルのボタンの中に表示する (Resume ↩ / Jump ↩ / Branch ⌘↩ / View →)。移動のキーは、キーの案内に表示する (1 列では下部パネルの左側、2 列では左の列のフッター)。同じキーを 2 か所に表示しない。 表示するキーはフォーカスの位置で変わる — 検索欄にフォーカスがある間は、キーの案内に ↩ List だけを表示し、 下部パネルのボタンを表示しない
  • 会話ペインは長い文章の閲覧を主目的として構成する: 主な内容は「自分の短い依頼 → Claude の長い発言」の繰り返しである。どの発言にも You / Claude のラベルを付け、 自分の発言には全幅の帯の地を付ける。Claude の発言は Markdown を描画した本文として扱う
  • 一覧と会話ペインは背景で区別する: 一覧は淡い地に行の枠を配置し、 会話ペインは通常のウィンドウ背景にする。選択する場所と閲覧する場所を背景で判別できる
  • Starred または Recent に残る実行中の会話は文字の印で示す: 1 行目(ラベル)の末尾に running。 状態記号(スピナー・!)は Running の区画の行だけが使用する — running の印は 最後に一覧を取得した時点の情報であり、現在の status を示さない
  • アイコンは線画の SVG(絵文字を使用しない)。状態記号の凡例は UI に配置しない (吹き出し ! / 瞬くスピナー / 薄い ✻ は形で判別できる)

見出し行

  • ポップオーバーとウィンドウの上端は見出し行 1 行である。ポップオーバーは左から 検索欄 / Refresh / Open in window / ⌄、1 列のウィンドウは 検索欄 / Refresh / Open in popover / ピン / ⌄ を並べる (Refresh は、ボタンの並びの左端にある。Open in popover は、ポップオーバーの Open in window と同じく、Refresh のすぐ右にあり、ピンはその右にある)。ウィンドウはタイトルバーを表示せず、 見出し行の左端に信号機ボタンを配置する(挙動は DESIGN.md §4.5「見出し行」)
  • 2 列のウィンドウの見出し行は、2 つの列にまたがって、ウィンドウの幅の全体を使用する。左から、信号機ボタン / 検索欄 (ポップオーバーと 1 列のウィンドウと同じく、次の要素の直前まで伸びる — DESIGN.md §4.5「見出し行」)/ 会話の中のヒットのカウンタと ‹ ›(検索中で、選択中の会話にヒットがある間だけ。表示している間は、その幅と間隔の分だけ、検索欄が短くなる)/ Refresh / Open in popover / ピン / ⌄ を並べる。見出し行の下に、区切り線を表示する(図は下記「2 列」)
  • Refresh のボタン: ほかの見出し行のボタンと同じ 24×24 で、アイコンは時計回りの円弧の矢印。ツールチップは Refresh (⌘R)。 実行中は、アイコンが時計回りに回転し(1 秒で 1 回転)、ボタンは押せず、不透明度 40% で表示する(ツールチップは Refreshing…)。 「視差効果を減らす」が ON の間は、回転しない(挙動は DESIGN.md §4.5「見出し行」/ §4.6)
  • 全画面のウィンドウ: 見出し行を画面の上端に表示する。信号機ボタンが無いので、その分の左の空きを取らず、検索欄は左端の余白から始まる。 そのほかの並びと余白は、全画面でないウィンドウと同じ(挙動は DESIGN.md §4.5「見出し行」)
  • 検索欄のプレースホルダは Search (2+ characters)。先頭に虫眼鏡のアイコン(13px・二次色)
  • 検索欄の形: 高さ 28px(見出し行のボタンは 24px で、上下の中心をそろえる。ウィンドウの見出し行は、検索欄の上と下の余白を同じ値にする — 12px ずつ。DESIGN.md §4.5「文字の大きさ」)・角丸 6px・ 行の枠と同じ色の地 + 1px の枠・左右の余白 8px・アイコンと文字の間隔 6px・文字 12px。 地とアイコンはアプリが描画し、その中に枠なしの入力欄を配置する(DESIGN.md §4.6「検索欄」)。 フォーカスリング・最近の検索のメニューは表示しない。文字がある間だけ、右端に消去のボタン (12px の塗りつぶした円に ×)を表示する(DESIGN.md §4.6「検索欄」)。 地のどこをクリックしても、入力欄にフォーカスが移る
  • Open in window(ポップオーバーの見出し行。ツールチップ Open in window): ウィンドウの枠のアイコン。 静止時は背景なし。ホバーでグレーの背景を表示し、押下で一段濃くする
  • Open in popover(ウィンドウの見出し行。ツールチップ Open in popover): 上の辺の近くにメニューバーの線があり、 その下に上向きの矢印がある角丸の四角のアイコン。大きさ、線の太さ、背景の表示は、Open in window と同じである (どちらのボタンも、表示の形を変更する。DESIGN.md §4.5「表示の形」)
  • ピン(ツールチップ Keep on top): 斜めに傾いた画びょう(16 の格子・線の太さ 1.2)。 OFF = 輪郭だけ・二次色 / ON = アクセントカラーの塗り + ボタンの背景(アクセントカラーの 16%。押している間は 24%。ホバーでは変更しない) (DESIGN.md §4.5「ピン」)
  • ⌄: 常に表示するチップ(正方形 24×24・角丸 7px)を背景に持つ。 前景色ベースで 通常 10% / ホバー 16% / プレス 24%。グリフの色は変更しない。 メニューの内容(ネイティブメニュー項目)は OS 標準のハイライトのまま

一覧のページ(1 列): Running・Starred・Recent

  • 区画は上から Running、Starred(スター付きの会話)、Recent(それ以外の過去の会話)の 3 つである。 Starred と Recent は、History の見出しの下に表示する。本ページの「History の行」は、Starred の行と Recent の行の総称である (DESIGN.md §4.5「一覧は 3 つの区画」)
  • 見出しは 2 種類: Running と History の見出しは、一覧の幅いっぱいの帯である(左右に余白が無く、角を丸めない。 淡い灰色の地で、上端と下端に区切り線を引く)。Starred と Recent の見出しは、地の無い、文字と線の見出しである (行数と山形の間の残りの幅に、細い線を引く)。どの見出しも、左から、名前(12px・太字)、行数(二次色 11px)、右端に山形を表示する。 名前の左端は行の文字の左端に、山形の右端は行の記号と時間の列の右端にそろえる(2 種類で同じ位置である)。 一覧の最初の帯は、見出し行のすぐ下に、間を空けずに配置する(寸法は下記「区画の開閉と行のドラッグ」)
  • 行数と、表示しない見出し: Running、Starred、Recent の見出しは、その区画の行数を表示する。 Recent の行が上限を超えている間は、行数の位置に first 100 を表示する(DESIGN.md §4.6「Recent の区画」)。 行が 1 つも無い区画は、見出しごと表示しない。History の見出しは、Starred に行がある間は、行数を表示しない。 Starred に行が無い間は、Recent の見出しも表示せず、History の見出しのすぐ下に Recent の行の枠を表示する。 この間は、History の見出しが、Recent の見出しと同じ行数を表示する(History 85、History first 100)。 Starred と Recent のどちらにも行が無い間は、History の見出しも表示しない(DESIGN.md §4.5「一覧は 3 つの区画」)。 検索中の見出しと行数は、下記の検索中の図と「区画の開閉と行のドラッグ」の「検索中の見出し」のとおりである
  • 区画の行は、1 つの枠の中に並べる: 枠は、角丸 10px・1px の枠線・地を持つ。行と行の間に隙間は無く、 1px の区切り線で区切る。区切り線は、行の文字の左端(枠線の内側から 11px)から、枠の右端(枠線の内側)までの線で、 色は枠線と同じである。行ごとの枠は無い(DESIGN.md §4.5「一覧は 3 つの区画」)
  • 行の構成はどの区画も共通: 左に 3 行の文字 / 右に記号と時間の列(Running の行は幅 28px、History の行は幅 44px)。行の内側の余白は、上 8px・下 9px・左 11px・右 8px である。 文字は、行の左の余白から始まる。 3 行は、上から、ラベル(二次色 11px)/ タイトル(13px・太字)/ 最後の発話(二次色 11px)である。 タイトルは、どの行も太字で表示する。ラベルとタイトルの間隔は 1px、タイトルと最後の発話の間隔は 4px で、 ラベルとタイトルを 1 組にして、最後の発話と区別する(間隔は DESIGN.md §9)。 記号と時間の列は、上に記号(状態記号は 20px、スターと三点リーダーは 16px。20px の枠の上端は 1 行目 = ラベルの位置)、下に経過時間(ラベルと同じ二次色 11px。 3 行目 = 最後の発話の位置)を、列の右端にそろえて表示する。3 行の文字は、どの行も列の手前で終わり、末尾を省略する(ellipsis)。 経過時間は省略しない(列の幅に収まらない場合は、その行の列を広げる)。 行の中にボタンは無い(スターと三点リーダーを除く)(DESIGN.md §4.5「一覧は 3 つの区画」)
  • Running の行: 列の上 = 状態記号。1 行目 = ラベル、 2 行目 = タイトル(waiting の間は許可内容)、3 行目 = 最後に自分が送った発話 (内容の規則は DESIGN.md §4.5「Running の行」)。選択中は、下部パネルの主ボタンが Jump になる
  • Starred と Recent の行: 列の上 = 左からスター、三点リーダー(下記「Archive」)。1 行目 = フォルダラベル、 2 行目 = タイトル、3 行目 = 最後に自分が送った発話。 選択中は、下部パネルの主ボタンが Resume になる。Starred の並びは利用者が決めた順序、Recent の並びは新しい順である (DESIGN.md §4.6「Starred の区画」「Recent の区画」)
  • Starred または Recent に残る実行中の会話: 1 行目(ラベル)の末尾に · running。 選択中は、下部パネルの主ボタンが disabled の Jump(ツールチップ Running in a terminal Shiibar CC can't drive)になり、Branch は通常の表示
  • 未確認(unreviewed)= 状態記号の右肩の赤バッジ(明色ハロー付き。 トレイアイコンの「窓の右肩のバッジ」と同じ文法 — menubar-design.html)。タイトルの太さでは未確認を示さない。 行の右端には未確認の印を配置しない
  • クリック: スターと三点リーダー以外の部分をクリックすると、その行を選択する。 青で表示している選択中の行をクリックすると、選択を解除する(選択なしになる)。 灰色で表示している選択中の行をクリックしたときは、選択を解除せず、一覧にフォーカスを移す (ウィンドウが key でなかった場合は、key にする)。クリックでは詳細ページを開かない。 行のクリックは、一覧にフォーカスを移す(検索欄のカーソルは消える。 DESIGN.md §4.5「行のクリック」「キー操作」)
  • ダブルクリック: スターと三点リーダー以外の部分をダブルクリックすると、 その行を選択し、一覧にフォーカスを移して、Jump(Running の行)または Resume(History の行)を実行する。 ⌘ を押しながらダブルクリックすると、Jump / Resume の代わりに Branch を実行する (⌘ を押しているかどうかは、2 回目のクリックの時点で判定する)。 対応するボタンが disabled のときは、選択とフォーカスの移動だけを行う。行の状態(未選択・青・灰色)による違いは無い。 ダブルクリックでは選択を解除しない。そのため、青で表示している選択中の行のクリックによる選択の解除は、 マウスのボタンを押してからシステムのダブルクリックの間隔が経過した時点で実行する (History の行でボタンを押したままの場合は、ボタンを離した時点 — DESIGN.md §4.5「行のドラッグ」)。 3 回以上の連続したクリックは、Jump / Resume を再実行しない(DESIGN.md §4.5「行のダブルクリック」)
  • ホバーと選択: どちらも、行の全体の地の色で示す(行ごとの枠は付けない)。 ホバー中の行は淡い灰色の地にする(どの区画の行も同じ。行のドラッグ中は付けない。DESIGN.md §4.5「行のクリック」)。 選択中の行は、キーの操作対象が一覧である間(ポップオーバーまたはウィンドウが key で、かつ一覧に フォーカスがある間)は淡い青の地、検索欄にフォーカスがある間と、 ウィンドウが key でない間(他のアプリを操作している間など)は淡い灰色の地にする (キーの操作対象が一覧かどうかを、色で区別する。DESIGN.md §4.5「行の選択」)。ホバーの地は、灰色の選択の地より淡い色にする。 選択中の行は、ホバーしても地の色を変更しない。枠の最初の行と最後の行の地は、枠の角丸の内側に収める。 区切り線は、ホバー中の行と選択中の行でも表示する。文字・経過時間・状態記号・スターの色は、 選択中も変更しない。選択している行は 0 行または 1 行で、 利用者が行を選択するまでは、どの行も選択していない(DESIGN.md §4.5「行の選択」)。見出しとフッターにはホバーの表示を付けない
  • 固定フッター(スクロールに含めない): 上から警告行、メッセージ行、下部パネル。 下部パネルは詳細ページと同じもので、左側にキーの案内、右側に選択中の行の View、Branch、主ボタンを配置する (View は一覧のページだけに表示する)。 行を選択していない間は、キーの案内だけを表示する(パネルの高さは変わらない)。 下部パネルの上端は 1px の区切り線(下記「固定フッター」「下部パネルの状態」)
  • UI 文言は英語。行の内容(依頼文・許可内容・タイトル)は利用者のデータをそのまま表示する

行の構成要素: 記号と時間の列・状態記号・スター・三点リーダー

  • 記号と時間の列(行の右端): 上に記号、下に経過時間(二次色 11px)を、 列の右端にそろえて表示する。記号は、Running の行が状態記号(20px)、Starred と Recent の行が、左からスター(16px)、三点リーダー(16px)である。 どの記号も 20px の枠の中心に表示する。Running の行の状態記号の枠と、History の行の三点リーダーの枠は、列の右端の同じ位置にあり、 スターの枠は、その左(間隔 4px)にある。列の幅は、Running の行が最小 28px、History の行が最小 44px である。 枠の上端は 1 行目(ラベル)の位置に、経過時間は 3 行目(最後の発話)の位置にそろえる。 行の左端には、記号のための場所は無い(DESIGN.md §4.5「一覧は 3 つの区画」/ §9)
  • 状態記号(記号と時間の列の上・20px 相当。Running の行): 薄い ✻(静止・50% 濃度)= idle(U+273B の文字グリフ。Claude Code の TUI が 処理を終えたときに表示する「✻ Worked for Ns」のマーカーと同じ「静止している Claude」)/ グリフ循環スピナー(100% 濃度)= working (Claude Code の TUI と同じ · ✢ ✳ ✶ ✻ ✽ の循環。位置 = round((1−cos(2πt/2000))/2 × 5) — 周期 2 秒のコサインイージングで、両端に留まり中間を速く通過する。等間隔のステップにしない。 動作させる条件は DESIGN.md §4.5「表示中の更新」)/ 輪郭だけの吹き出し + 太い ! = waiting(塗りなし — Claude が利用者に話しかけて返事を待っている)。 モックは静止画のため、working は循環の 1 コマ(✻)を示す(idle との差は濃度のみ)
  • 赤バッジ: 状態記号の右肩に表示する塗りの円 + 細い明色のフチ(ハロー)。 状態記号の種類によらず同じ位置
  • スター(記号と時間の列の上・16px。状態記号より小さい。Starred と Recent の行): 三点リーダーの枠の左の、20px の枠の中心に表示する。クリックに反応する範囲は、20px の枠である。 線の太さは、輪郭だけの星が 1.1px、塗りの星が 0.7px である。3 状態 — なし(Recent の行。スターの枠は空)/ Recent の行のホバー中 = 輪郭だけの星(二次色)/ スター付き(Starred の行)= 黄色の塗りの星(塗り #f5b400・輪郭 #d39700。 ホバーしていなくても表示する)。スターのクリックでは行を選択しない。挙動は DESIGN.md §4.6「スター」
  • 三点リーダー(記号と時間の列の上の右端・16px。Starred と Recent の行): 横に並ぶ 3 つの点を、二次色で、常に表示する。 クリックに反応する範囲は、20px の枠である。クリックすると、項目が Archive の 1 つのメニューを表示する(下記「Archive」)。 クリックでは行を選択しない。Running の行には表示しない。ツールチップは More。挙動は DESIGN.md §4.6「Archive」

メッセージ面の文法

  • 発言ごとにラベルの行: どの発言も、先頭に役割のラベル(11px・セミボールド)を表示する。 自分の発言は You(青)、Claude の発言は Claude(二次色)。1 つの依頼に Claude の発言が連続するときも、 すべての発言にラベルを付ける(発言の境目を示す)。ラベルは描画後テキストに含めない (ヒット計算・畳み境界・選択とコピーの対象外 — DESIGN.md §4.6)
  • 自分の発言 = 全幅の帯: 左端から右端までマージンなしで、ラベルと発言に帯の地を付ける。 発言は本文と同じウェイトで表示する。 太字にしない(帯が見出しの役割を持つので、文字を強調しない)。発言の文字は 13.5pt(文字の大きさ 13 のとき)。 帯の直前は広めの余白(節の切れ目)。スクロールすると、帯の並びから依頼の一覧を把握できる
  • Claude の発言 = Markdown を描画(描画範囲は DESIGN.md §4.6「会話ペインの表示」): コードブロックはモノスペース + 淡い背景 + 横スクロール。インラインコード・強調・見出し・ 箇条書きも描画する。地は付けない
  • パイプ表はグリッドで描画: ヘッダ行はセミボールド + 淡い背景、行間に罫線、 全列左揃え(列揃えの指定は無視)。セルの中のインライン(コード・強調)も描画する。 表は内容の幅のまま(本文の幅いっぱいに広げない)。セルは幅の上限(約 28em)で 折り返し、それでも収まらない表だけ、コードブロックと同じく表の中で横スクロール (DESIGN.md §8.38)。等幅フォントで整形する形は採用しない — 日本語のグリフ幅が モノスペースで揃わず、列が崩れる(DESIGN.md §8.37)
  • 発言ごとのコピー: 各発言のラベルの行の右端に、コピーのアイコンボタン (14px・二次色)を常に表示する。本文の文字と同じく、ミニマップの手前 8px より内側に配置する。 押した後は一定時間、アイコンをチェックマークに替える(同じ位置・同じ大きさ・同じ色。 表示時間は DESIGN.md §9、コピーする内容は §4.6「発言ごとのコピー」)
  • 選択とコピー(文法の正は DESIGN.md §4.6「選択とコピー」): 選択ハイライトは メッセージをまたいで連続する。ラベル・展開 / 畳みのボタン・コピーのボタンは 選択に含まれない。右クリックメニューは Copy(⌘C)/ Copy as Markdown(⇧⌘C)の 2 項目だけ
  • 本文の幅の上限: 本文の行長は約 60em を上限とする。ウィンドウを広げても行が 長くなりすぎない(コードブロックと、折り返しても収まらない表は、この上限の内側で横スクロール)
  • 本文の既定は 13pt・行間 1.7。コードブロックは 11.5pt(文字の大きさ 13 のとき)。 行間・段落間・ブロック間隔・帯の余白は本ページの CSS 値が実装の正(DESIGN.md §8.39)
  • ミニマップ = スクロールバー(右端・常時・幅 20pt): 会話全体の略図 (帯 = 濃い縞・本文 = 淡い塊・コード = 中間。文字は描かない)+ 半透明グレーのつまみ。 本文の文字はミニマップの手前 8px で折り返す(狭くなるのは文字の列だけ — 帯の背景は 右端まで、コードブロック・表の背景は元の列幅のまま)。 ドラッグでスクロール・ホバーで濃く・地のクリックでジャンプ。会話ペイン内に OS のスクロールバーは 表示しない(DESIGN.md §4.6「ヒットナビゲーション」/ §8.39)
  • 下端の手がかり: 最後のメッセージの下に終端マーカー Latest message · 3h ago(罫線ではさんだ淡い一行)。上に続きがある間だけ ヘッダ下に薄いスクロールシャドウ(最上部で消える)
  • メッセージ間のツール実行は何も描かない(DESIGN.md §4.6)

検索(2 文字以上): ヒットの位置は会話ペインが示す

  • 挙動の正は DESIGN.md §4.6(「検索の適用範囲」・「検索欄」・「ヒットナビゲーション」)。 ここでは形だけを示す(モックは上記「一覧のページ」「詳細ページ」「2 列」の検索中の図)
  • 検索は 1 つ: 見出し行の検索欄の検索文字列が、一覧の絞り込みと、会話内のヒットの両方に 適用される
  • 一覧の行の形は空クエリのときと同じ。ヒットの抜粋も件数も表示しない。 Running の区画も、結果に含まれる行だけになる。検索中は、Running と History を開いた状態で表示し、見出しは帯の形のままで、 山形と Running の印を表示しない。History の見出しの下には、Starred の行(利用者が決めた順序)と Recent の行(新しい順)を、 この順に、1 つの枠の中に表示し、Starred と Recent の見出しは表示しない。検索中は、行をドラッグできない
  • ハイライトはすべての検索語を同じ色で表示し、現在位置だけ濃くする
  • 検索バー行(ヘッダの下)は macOS 標準の文書内検索の形: カウンタ N of M + ‹ › の セグメンテッドコントロール(内容サイズ — バーの幅いっぱいに広げない)。 N は、会話の先頭のヒットを 1 として数える。2 列では、検索バー行を表示せず、カウンタと ‹ › を見出し行の検索欄と Refresh のボタンの間に配置する。 1 列の詳細ページでは、左端に Matches for “tag” の文を表示し(Matches for は二次色、 引用符で囲んだ検索文字列は通常の色。長い検索文字列は途中を省略する)、カウンタと ‹ › を右端に配置する。 この文は表示だけで、入力欄と区別できるように地・枠・虫眼鏡のアイコンを付けない
  • ヒットの分布はミニマップに線で表示する(現在位置だけ濃い線)。畳まれたメッセージの表示していない部分に ヒットがあるときは、展開ボタンに件数バッジ N matches(ハイライト色)

キー操作

  • 挙動の正は DESIGN.md §4.5「キー操作」。キーの動作は、検索欄にフォーカスがあるかどうかで 2 通りに分かれる。 「一覧にフォーカスがある」は、検索欄にフォーカスが無い状態を指す(詳細ページと、会話ペインにフォーカスがある場合を含む)。 検索欄にフォーカスがある間は検索欄にカーソルを表示し、一覧にフォーカスがある間は表示しない
  • 移動のキーはキーの案内に、実行のキー(↩ と ⌘↩)と詳細ページを開くキー(→)は下部パネルのボタンの中に表示する
キー検索欄にフォーカスがある間一覧にフォーカスがある間
↑ ↓何もしない前後の行に選択を移動する(閉じている区画の行は対象にしない)。選択なしの間は、先頭の行を選択する。1 列の詳細ページでは、会話をスクロールする(Space と Page Up / Page Down も同じ)
⌥↑ ⌥↓検索欄のカーソルを移動する1 列の詳細ページで、表示する会話を前後の行の会話に切り替える(選択も移動する。スライドはしない。端では何もしない)。それ以外では何もしない
↩一覧にフォーカスを移す。選択なしの間は、先頭の行を選択する。行が 1 つも無いときは何もしないJump または Resume(下部パネルの主ボタンと同じ)
⌘↩何もしないBranch(下部パネルの Branch と同じ)
→検索欄のカーソルを移動する1 列の一覧のページで、選択中の行の詳細ページを開く(下部パネルの View と同じ。選択なしの間は何もしない)
←検索欄のカーソルを移動する1 列の詳細ページで、一覧のページに戻る
文字の入力 / delete検索欄に入力する何もしない
⌘G ⇧⌘G会話内の次のヒット / 前のヒット(会話ペインを表示している間だけ)同じ
⌘F何もしない検索欄にフォーカスを移す。1 列の詳細ページでは、一覧のページに戻ってから移す
⌘= / ⌘+ / ⌘− / ⌘0文字の大きさを変更する(下記「文字の大きさ」)。どのページでも同じ同じ
escポップオーバーを閉じる。ウィンドウでは何もしない。行のドラッグ中は、ドラッグの取り消しだけを実行する。Archive の一覧を表示している間は、通常の一覧に戻る操作だけを実行する(ポップオーバーを閉じない)同じ
  • 検索欄では文字の編集だけを行い、行の操作は一覧で行う
  • 一覧にフォーカスを移す操作: 検索欄での ↩、行のクリック、行のドラッグの開始。 検索欄にフォーカスを移す操作: 検索欄のクリック、⌘F
  • Tab と ⇧Tab は標準のフォーカスの移動である。1 列の詳細ページを表示している間は、 一覧のページのビュー(検索欄など)を、Tab と ⇧Tab の移動先にしない(DESIGN.md §4.5「キー操作」)
  • 選択なしの間と、対応するボタンが disabled のとき、一覧にフォーカスがある間の ↩ と ⌘↩ は何もしない。 日本語入力の変換が未確定の間は、すべてのキーを日本語入力に渡す

文字の大きさ

  • 通常の調整は ⌘=(⌘+ も同じ)/ ⌘− / ⌘0(13 に戻す)、 設定として表示する場所は Settings の General の Text size(数値の入力欄とステッパー)。 範囲と既定は DESIGN.md §9、挙動は同 §4.5「文字の大きさ」/ §4.6「会話ペインの文字の大きさ」
  • 対象はポップオーバーとウィンドウの全体(一覧、見出し行、下部パネル、会話ペイン)。 本ページの寸法は、文字の大きさが 13 のときの値である。文字の大きさ、行の高さ、上下の余白、アイコン、検索欄の高さ、 見出し行のボタンと会話ペインのヘッダの戻るボタン(大きさとアイコン)、 行の記号と時間の列の幅、 ポップオーバーの幅と 2 列のときの一覧の列の既定の幅は、13 に対する比率で連動する。左右の余白、角の半径、 枠線の太さ、ボタンの左右の間隔、ミニマップの幅は固定である
  • フォントの切り替えは持たない — Markdown の描画により、コードは常にモノスペースで表示されるため
