## 背景

文字の大きさの設定は、会話ペインの本文だけに適用される。一覧、見出し行、下部パネルの文字の大きさは
変更できない。設定を 1 つのまま、ポップオーバーとウィンドウの全体に適用する。

## タスク

### T1: Core — 値と比率

- `ConversationsTextSize` を、全体の設定を表す型(`TextSize`)に変更する。範囲 9〜18 の整数、既定 13、
  比率 = 値 / 13。次の計算を Core に実装し、ビューとコントローラに記述しない
  - 保存済みの値の解釈(整数でない値は四捨五入、範囲の外は範囲の端。値が無い場合は 13)
  - ⌘= / ⌘− / ⌘0 の次の値(範囲の端と、13 での ⌘0 は「変更なし」)
  - Settings の入力欄の文字列の解釈(前後の空白は無視。整数以外は `Enter a whole number`、
    範囲の外は `Enter a number from 9 to 18`)
  - ポップオーバーの幅と、2 列のときの一覧の列の幅(420 × 比率を四捨五入)、2 列になる幅(一覧の列の幅 + 460)
- `ColumnMode.forWindowWidth` は、文字の大きさ(または一覧の列の幅)を引数に追加する
- UserDefaults のキー(`cc.shiibar.conversationsTextSize`)は変更しない。保存する値は整数にする。
  読み込みは、整数と、以前に保存された小数の両方に対応する。読み込みだけでは、保存済みの値を書き換えない
- 型とファイルの名前(`ConversationsTextSize`、`ConversationsTextSizeStore`)は、全体の設定を表す名前に変更する

### T2: ポップオーバーとウィンドウ(ネイティブの表示)

- §4.5「文字の大きさ」の「比率で連動する寸法」と「固定の寸法」のとおりに、一覧、見出し行、下部パネル、
  キーの案内、会話ペインのヘッダと検索バー行の寸法を変更する
- 比率は、2 つの画面の根(ポップオーバーとウィンドウの `MainSurfaceView`)から SwiftUI の環境値で渡す。
  寸法の計算(基準の値 × 比率)は、基準の値を名前付きの定数にして 1 か所にまとめる
  (ビューの中に、基準の値の数値を直接記述しない)
- 検索欄(`ConversationsSearchField.swift` の `SearchFieldView`)は、寸法を初期化のときに固定している。比率の変更に追従するように、
  文字の大きさ、高さ、アイコン、消去のボタン、制約の定数を更新する
- ポップオーバーの幅は、開くときと、表示している間に値が変化したときに設定する。高さは変更しない
- ウィンドウは、大きさと最小の大きさを変更しない。見出し行は、行の高さが変化しても、信号機ボタンと
  上下の中心をそろえる(1 列の一覧のページ、1 列の詳細ページ、2 列のそれぞれ)
- スクロール位置は、§4.5「文字の大きさ」の「スクロール位置」のとおりにする
- 文字の大きさの変更で列の数が変化した場合は、§4.5「幅による切り替え」の「幅を変更したとき」の規則を適用する

### T3: 会話ペインのメッセージ面(WKWebView)

- §4.6「会話ペインの文字の大きさ」のとおりに、メッセージ面のすべての文字の大きさと上下の余白を、比率で連動させる
  (本文との差で指定している大きさ — コードブロック、見出し、自分の発言 — も、13 のときの値に対する比率にする)。
  13 のときの計算後の値は、変更の前と同じにする(`window-design.html` の CSS 値。§8.39)
- 左右の余白、角の半径、枠線、ミニマップの幅と、その手前の折り返しの余白は固定にする
- 比率は、文字の大きさと一緒にページに渡す(CSS の変数)。プロセスの再起動の後と、表示を保留している間の
  再送の対象に含める

### T4: Settings

- §4.5「Settings ウィンドウ」のとおりに、General の Appearance の次に Text size を配置する
  (数値の入力欄とステッパー、説明、エラーの表示)。Conversations 節は削除する
- 入力欄の検証と、エラーの文言は、T1 の Core の計算を使用する
- ポップオーバーとウィンドウのキーで値が変化したときに、入力欄の表示を更新する

### T5: 文書

- `docs/` は編集しない。仕様と実装の食い違いを見つけた場合は、完了報告で提案する

## テスト要求

- Core: 範囲と既定、比率(9 / 13 / 18)、保存済みの値の解釈(無し / 小数 / 範囲の外)、キーの次の値
  (範囲の端、13 での ⌘0)、入力欄の文字列の解釈(前後の空白、整数以外、範囲の外、エラーの文言)、
  ポップオーバーの幅と一覧の列の幅(9 のとき 291、13 のとき 420、18 のとき 582)、2 列になる幅の境界
  (9 のとき 751、13 のとき 880、18 のとき 1042 と、それぞれの直前の値)。以前の保存値 19 と 20 を 18 として扱うこと
- App: 保存と読み込み(一時的な UserDefaults のドメインを使用する。整数と小数の読み込み、
  読み込みだけでは保存済みの値を書き換えないこと)。キーの操作が、保存の値と、
  会話ペインへの送信の値を変更すること。範囲の端で、保存も送信も発生しないこと
- App: Settings の入力欄の適用(有効な値、整数以外、空の入力、範囲の外、同じ値)、エラーの表示の消去、
  ステッパーの範囲の端、キーで変更したときの入力欄の更新
- Core または App: 文字の大きさの変更で列の数が変化したときの、表示するページと選択
- WebPaneKit: 13 のときの計算後のスタイルが、既存のテストの値と同じであること(既存のテストを変更しない)。
  18 のときに、ラベル、コードブロック、見出し、上下の余白が比率で変化し、左右の余白とミニマップの幅が
  変化しないこと。再送の後も比率が保持されること
- 既存のテストを弱めない。寸法の基準の値を変更するテストの修正は、仕様の変更に対応する箇所に限定する
- テストは、実際の UserDefaults の標準ドメイン、state dir、ペーストボードを使用しない
- docs/ 以外に日本語を記述しない

## 完了条件

- `swift build --build-tests -Xswiftc -warnings-as-errors` と `swift test -Xswiftc -warnings-as-errors` が
  警告なしで成功する
- 所有者の実機スモーク:
  1. Text size が 13 のとき、ポップオーバーとウィンドウの表示が、変更の前と同じである
  2. ポップオーバーとウィンドウで ⌘= / ⌘− / ⌘0 を押すと、一覧、見出し行、検索欄、下部パネル、会話ペインの
     文字、行の高さ、アイコンが連動して変化する。9 と 18 で、文字と記号が欠けず、行が重ならない
  3. ポップオーバーを表示したまま ⌘= / ⌘− を押すと、ポップオーバーの幅が変化する。高さは変化しない。
     ポップオーバーの高さが 300pt、文字の大きさが 18 のとき、行が 1 枚以上表示され、下部パネルが欠けない。
     画面の端の近くでも、ポップオーバーが画面の中に表示される
  4. ウィンドウは、大きさが変化しない。2 列のときの一覧の列の幅が変化する。幅が不足すると 1 列になる。
     見出し行と信号機ボタンの上下の中心がそろっている(9 / 13 / 18。1 列と 2 列)。
     2 列の右の列のヘッダが、18 のときに上端で欠けない。
     ウィンドウの幅が 360pt、文字の大きさが 18 のとき、下部パネルのボタンが欠けない。
     ⌘= で 2 列が 1 列になる場合と、⌘− で 1 列が 2 列になる場合に、選択が保持される
  5. Settings の Text size の入力欄に値を入力して Enter を押すと、表示中のポップオーバーまたはウィンドウに
     反映される。入力欄を編集してからフォーカスを外した場合(Settings の中の別の項目のクリックと、
     別のウィンドウのクリック)も反映される。値を入力して、Enter を押さずに Settings ウィンドウを閉じた場合
     (赤ボタンと ⌘W)は、反映されない。ステッパーで 1 ずつ変化する。
     `abc` と `19` で、それぞれのエラーが表示され、入力欄が元の値に戻る。次に値を適用すると、エラーが消える
  6. アプリを再起動した後も、値が保持される。変更の前に会話ペインの文字の大きさを変更していた場合は、
     その値が引き継がれる(19 と 20 は 18 になる)
  7. トレイアイコン、Settings ウィンドウ、Setup Check ウィンドウ、⌄ のメニューの大きさは変化しない
  8. 会話ペインで、検索のハイライトとヒットの移動、ミニマップ、メッセージの畳みが、9 と 18 でも動作する
  9. ⌘+(⇧ を使用する入力)と、検索欄にフォーカスがある間のキーの操作でも、文字の大きさが変化する。
     文字の大きさが 18 のとき、検索欄での日本語入力の変換中の表示が欠けない
  10. 文字の大きさを変更したとき、一覧の表示範囲の先頭の行が保持される
