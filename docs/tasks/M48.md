## 背景

2 列のときの一覧の列の幅は固定で、利用者が変更できない。列の境界をドラッグして変更できるようにする。

## タスク

### T1: Core — 幅の計算

- 次の計算を Core に実装し、ビューとコントローラに記述しない
  - 表示する幅: 記憶した幅がある場合は、記憶した幅を、最小の幅(280pt)と「ウィンドウの幅 − 460pt」の
    範囲に収めた値(460pt は、境界の線の 1pt を含む)。記憶した幅が無い場合は、既定の幅(文字の大きさに連動する値)
  - ドラッグ中の幅: ドラッグを開始した時点の表示する幅に、ドラッグの移動量を加えて、同じ範囲に収めた値
  - 記憶する値: ドラッグを終了した時点の幅(四捨五入)が、開始した時点の表示する幅(四捨五入)と違う場合だけ、その値
    (移動のないクリックと、移動して元の位置に戻した場合は、記憶しない)
  - 保存済みの値の解釈(数値でない値と、0 以下の値は、記憶した幅が無いものとして扱う)
  - これらの計算は、2 列のときだけ使用する。範囲の最大が最小より小さい場合は、最小を使用する
- 2 列になる幅は変更しない(既定の幅 + 460pt)
- UserDefaults のキーを追加する(`MainSurfaceDefaultsKeys`)

### T2: ドラッグ領域と表示

- 列の境界(幅 1pt の線)の上に、幅 8pt のドラッグ領域を配置する(線の中心から左右 4pt ずつ)。ドラッグ領域は、
  その位置にある他の表示よりも先にマウスの操作を受け取る。カーソルは左右リサイズの形にする
- ドラッグ中は、アニメーションなしで幅を追従させる。ドラッグの移動量は、画面の座標で取得する
  (ドラッグ領域が、境界と一緒に移動するため)。範囲は、その時点のウィンドウの幅で計算する。
  ドラッグ中に 1 列になった場合と、ウィンドウを閉じた場合は、ドラッグを終了し、記憶しない
- ダブルクリックで、記憶した幅を消去して、既定の幅に戻す(アニメーションなし。記憶した幅が無い場合は何もしない)
- ドラッグ領域は、2 列のときだけ配置する。ウィンドウの移動のドラッグ(見出し行の空いている部分)と
  競合しないようにする
- 一覧と会話ペインの表示(スクロール位置、選択、会話ペインの折り返し)は、幅の変更に追従する

  警告なしで成功する
- 所有者の実機スモーク:
  1. 2 列のとき、列の境界の上でカーソルが左右リサイズの形になり、ドラッグで一覧の列の幅が変化する。
     最小の幅と、右の列に最小の幅を残す幅で止まる。範囲の端を超えてから戻すと、境界がポインタに追従する。

     見出し行、行、フッターが欠けない
  2. アプリを再起動した後も、変更した幅で表示される
  3. 境界をダブルクリックすると、既定の幅に戻る。ダブルクリックの 1 回目のクリックで、幅が変化しない
  4. 一覧の列を広げた状態でウィンドウを狭めると、右の列に最小の幅を残して一覧の列が狭くなる。
     ウィンドウを広げると、記憶した幅に戻る。2 列になるウィンドウの幅は、変更の前と同じである
  5. 記憶した幅がある間は、⌘= / ⌘− / ⌘0 と Settings の Text size で、一覧の列の幅が変化しない。
     既定に戻した後は、連動する
  6. 境界の近くの操作(一覧のスクロール、行のクリック、会話ペインのミニマップと文字の選択、
     ウィンドウの移動)が、変更の前と同じように動作する
  7. 1 列のウィンドウとポップオーバーの表示は、変更の前と同じである
